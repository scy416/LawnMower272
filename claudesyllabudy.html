Who Are We?

University life throws scattered deadlines, inconsistent workloads and zero follow-up from lecturers at freshmen who are used to being guided. Five modules, each with random mid-term submissions, lab reports and project milestones — all invisible until they sneak up on you.

The existing NUSMods planner only shows class timings and final exams, leaving the actual academic timeline a mystery. SyllaBuddy solves this with a community-powered deadline tracker and senior connection platform.

✦ Core Features
📋
Assignment Timetable
Colour-coded by difficulty (Easy / Medium / Hard) based on past user data. Tick off completed tasks and spot heavy workload weeks at a glance.
👥
Social Interface
Connect with seniors who have taken your modules. Get personal advice, workload insights and real grades — not just official course descriptions.
👤
User Profile
Personalised profile with module ratings and comments. Track your academic journey and build your student network.
🤖
AI Chatbot Extension
Answers generic course questions instantly. Saves seniors' time and gives freshmen quick answers 24/7.
🔔
Push Notifications Extension
Smart reminders for uncompleted assignments. Never miss a deadline again.
🏗 Software Engineering Principles
🔀 Version Control
  • Git with structured branching & merging per feature
  • Feature branches tested thoroughly before PR merge
  • Small, frequent commits with meaningful messages
📌 Project Management
  • Agile approach — tasks planned before each milestone
  • GitHub Issues to log blockers and ensure timely resolution
  • Weekly check-ins to review progress and reassign tasks
🛡 Security & Data Protection
  • API keys & credentials stored in .env, never committed
  • User passwords hashed before saving to database
🧪 Testing Strategy
Unit
Unit Testing
Functions and backend algorithms tested in isolation to verify correct logic and data transformations.
Integration
Integration Testing
Combined modules tested together — especially timetable merging, module rating system, and chat flows.
User

Real NUS students test for usability, identify gaps in onboarding, and provide workload feedback.

💬 User Stories
As an incoming freshman exploring courses, I want to find and compare module workloads before bidding so I can make informed choices.
As a student taking a new module, I want to see exactly when assignments are due across all 13 weeks so I can plan ahead.
As a busy freshman juggling CCAs and coursework, I want to see which weeks are heavy at a glance so I can manage my time.
As a senior, I want to share my module experience and grades to help juniors make better academic choices.
